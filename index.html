    Your history, on every device.

    Connect a cloud database, then sign in with the same account on each device. The doctor directory always stays inside this page.

    Cloud connection

    First-time cloud setup
    1. Create a Supabase project and run the supplied cloud-setup.sql in its SQL Editor.
    2. In Authentication, create your own email/password user and confirm that user.
    3. Enter the project URL, publishable key, and that user's credentials here. Never enter a secret key.
    4. Repeat sign-in on your other devices. For simpler setup, fill in the public cloud-config block in the HTML before uploading.

    GitHub Pages alone cannot sync records. See START-HERE.md for the full setup and backup instructions.

    A copy you can keep.

    Export your history as a backup. Restoring merges records; it never replaces your current history. Previously deleted visits stay deleted.

    Device-only records can be lost if browser data is cleared. Cloud sync needs an active database and internet to upload new entries. Keep occasional exported backups.
